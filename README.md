# Loop — маршрут по интересным местам

Пешее приложение на Flask и Leaflet: пользователь ставит на карте точки **A** и **B**, выбирает категории мест, максимальный «крюк» и количество остановок — приложение подбирает остановки по пути и строит пеший маршрут по улицам.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть: <http://127.0.0.1:5000>.

Для доступа с телефона в той же Wi-Fi сети:

```bash
HOST=0.0.0.0 PORT=5050 python app.py
# затем открыть http://<IP-компьютера>:5050 на телефоне
```

> На macOS порт 5000 часто занят AirPlay Receiver (ControlCenter). Если `HOST=0.0.0.0` не запускается с ошибкой «Address already in use», используйте `PORT=5050` или отключите AirPlay Receiver в настройках macOS.

### Геолокация на телефоне

Браузеры разрешают `navigator.geolocation` только в безопасном контексте: `localhost` или **HTTPS**. По адресу `http://192.168.x.x:5050` кнопка «Моё местоположение» закономерно не сработает — это ограничение браузера, а не приложения.

Для проверки с телефона можно поднять локальный HTTPS с самоподписанным сертификатом:

```bash
IP=$(ipconfig getifaddr en0)   # macOS; подставьте IP компьютера в Wi-Fi
mkdir -p certs
openssl req -x509 -newkey rsa:2048 -nodes -days 365 \
  -keyout certs/key.pem -out certs/cert.pem \
  -subj "/CN=$IP" \
  -addext "subjectAltName=IP:$IP,DNS:localhost"

HOST=0.0.0.0 PORT=5050 \
  SSL_CERT=certs/cert.pem SSL_KEY=certs/key.pem \
  python app.py
```

На телефоне откройте `https://<IP>:5050`, примите предупреждение о самоподписанном сертификате и разрешите геолокацию. Папка `certs/` добавлена в `.gitignore`.

Альтернатива — `mkcert` или туннель `cloudflared`/`ngrok`, если нужен доверенный HTTPS.

## Источники данных и фолбэк

1. Сначала запрашивается **Overpass API** (официальное API и публичные зеркала).
2. Если все зеркала недоступны, ответ идёт из локального `saratov.geojson`.
3. Источники **не смешиваются**: когда Overpass снова заработает, локальные места просто перестанут использоваться. Дубликатов и конфликтов «локальное + живое» нет.
4. Кнопка **«Повторить запрос»** в уведомлении принудительно проверяет Overpass, даже если сработал предохранитель.
5. Неудачные зеркала временно (по умолчанию 90 секунд) исключаются из опроса, чтобы приложение не ждало таймаут на каждом запросе.
6. Результаты поиска кэшируются в памяти: живые — на 2 минуты, локальные — на 30 секунд.

Локальный набор содержит только Саратов, поэтому при выключенном Overpass и точках за пределами Саратова приложение честно сообщает, что мест нет.

## Настройки через переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `HOST` | `127.0.0.1` | Адрес сервера |
| `PORT` | `5000` | Порт |
| `FLASK_DEBUG` | выключен | `1`/`true` включает отладочный режим |
| `OVERPASS_TIMEOUT` | `8` | Таймаут запроса к Overpass, сек |
| `OVERPASS_COOLDOWN` | `90` | Пауза перед повторной проверкой упавшего зеркала, сек |
| `ROUTING_TIMEOUT` | `12` | Таймаут запроса к маршрутизатору, сек |
| `MAX_BBOX_DIAGONAL_KM` | `150` | Максимальный размер области поиска |
| `SSL_CERT` | пусто | Путь к сертификату для HTTPS |
| `SSL_KEY` | пусто | Путь к ключу сертификата |

`FLASK_DEBUG` по умолчанию выключен: интерактивный отладчик Werkzeug не должен быть доступен извне.

## Карта и геолокация

- Подложка карты — **всегда стандартные тайлы OpenStreetMap** (`tile.openstreetmap.org`), без внешних ключей и прокси.
- В тёмной теме те же OSM-тайлы приглушаются CSS-фильтром; источник карты не меняется.
- Если тайлы не загрузились, приложение показывает уведомление, а не «водяной знак» стороннего сервиса.
- Параметры «Отступ области», «Максимальный крюк» и «Максимум остановок» можно менять ползунком **и вводить числом с клавиатуры**. Значения синхронизированы; на мобильном открывается цифровая клавиатура.
- Для геолокации на телефоне нужен HTTPS (см. раздел выше). На `http://192.168...` приложение честно показывает подсказку и не выдаёт ложную ошибку «доступ запрещён».

## API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/points` | Совместимость: последнее состояние на сервере |
| `POST` | `/api/points` | Явно сохранить `point_a`/`point_b` или поставить точку по `lat`/`lon` |
| `POST` | `/api/search-places` | Найти места в bbox точек A и B |
| `POST` | `/api/build-route` | Подобрать остановки и построить пеший маршрут |

Новый фронтенд передаёт `point_a` и `point_b` в каждом запросе поиска/маршрута, поэтому два пользователя не перетирают точки друг друга. Серверный `/api/points` оставлен для обратной совместимости.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют валидацию координат, защиту от слишком большой области, локальный фолбэк, отсутствие смешивания источников и сборку маршрута.

## Безопасность и устойчивость

- Строгая CSP: скрипты и стили только с этого домена; Leaflet лежит локально в `static/leaflet`.
- Ограничение размера запроса (1 МБ) и валидация всех чисел (включая `NaN`/`Infinity`).
- Ограничение диагонали области поиска — защита Overpass и сервера от гигантских запросов.
- Проверка `Origin`/`Sec-Fetch-Site` для изменяющих POST-запросов.
- Все названия мест экранируются на клиенте — данные OSM не могут внедрить HTML/JS.
- Таймауты и предохранители для Overpass и OSRM; длинный маршрут режется на куски по лимиту OSRM.
- Таймауты `fetch` на клиенте, отмена устаревших запросов, блокировка повторных нажатий.

Ограничения: приложение не содержит аутентификации и rate limiting. Если публиковать его в интернете, стоит добавить reverse proxy, HTTPS, лимиты запросов и запуск через WSGI-сервер (например, gunicorn) вместо встроенного сервера Flask.
